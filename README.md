# CMS-Medicare-PartD-Analytics

CMS Medicare Part D Prescription Analytics Dashboard

# Project Overview

This project analyzes CMS Medicare Part D prescription data to uncover trends in prescription utilization, provider prescribing behavior, and Medicare drug spending.

The objective was to transform raw healthcare claims data into meaningful insights through SQL analysis and interactive Power BI dashboards that support healthcare decision-making.

# Business Problem

Healthcare organizations, pharmacy benefit managers, and policymakers need visibility into:

        Prescription utilization patterns
        Drug spending trends
        High-cost medications
        Provider prescribing behavior
        Geographic variations in healthcare utilization

This project demonstrates how healthcare data analytics can be used to identify cost drivers, utilization patterns, and opportunities for improved healthcare management.

# Dataset

Source: CMS Medicare Part D Prescriber Public Use File (PUF)

The dataset contains information on:

       Provider identifiers
       Provider specialties
       Drug names
       Total prescription claims
       Drug costs
       Beneficiary counts
       State information

# Key Insights

## Provider Insights

   Nurse Practitioners contributed a significant volume of prescription claims.
   Prescribing patterns varied considerably across provider specialties.
          
## Drug Spending Insights

   A relatively small number of specialty medications accounted for a large percentage of Medicare spending.
   High-cost medications were not always the most frequently prescribed drugs.
          
## Geographic Insights

  Prescription utilization and spending patterns differed across states.
  Certain regions demonstrated higher Medicare drug expenditures.
